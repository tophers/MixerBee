Webhook Setup Instructions
Emby: Server Settings → Notifications → Add Notification → Webhook. Paste this connection's full Webhook URL into the Webhook URL field. Set Request Content Type to application/json. Check: Playback Stop, Mark Played/Unplayed, and New Media Added.
Jellyfin: Dashboard → Plugins → Webhook → Add Destination. Paste this Webhook URL into the Webhook URL field. Check: Item Added, Playback Stop, User Data Saved. Ensure Send All Properties is checked.
